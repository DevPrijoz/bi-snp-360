# Política inicial de segurança do BI SNP 360°

Não publique dados institucionais internos, relatórios restritos, chaves, senhas, planilhas, arquivos do SEI ou informações pessoais no repositório ou nas páginas da demonstração.

Para relatos de segurança com potencial vazamento de dados públicos/privados, **não abrir issue pública com informações sensíveis**: acionar o responsável institucional pelo projeto e a área de segurança da informação do MPOR. Documentação técnica de controles e pré-requisitos: [docs/SEGURANCA.md](docs/SEGURANCA.md).

A versão estática é apenas demonstração fictícia. A API existe em modo piloto, sem integração corporativa e com acesso interno desabilitado por padrão na ausência de IdP configurado.
